## Continuity and differentiability: revision sheet

<!-- type: definition -->
**Definition (continuity).** A function f is continuous at a if the limit of f(x) as x approaches a exists and equals f(a).

**Definition (derivative).** f is differentiable at a if the limit of the difference quotient (f(x) − f(a)) / (x − a) as x approaches a exists and is finite. This limit is the derivative f'(a).

<!-- type: course -->
Differentiable implies continuous, but not the other way round: the absolute value function is continuous at 0 but not differentiable there. The intermediate value theorem says that a continuous function on [a, b] takes every value between f(a) and f(b), which is used to prove that an equation f(x) = 0 has a solution.
